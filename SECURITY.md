# Security policy

Please report vulnerabilities privately through GitHub: the **Security** tab of this repository, then **Report a vulnerability**. Don't open a public issue.

Include the version (`adrian version`), what you found, and how to reproduce it. Supported versions: the latest release.

How A.D.R.I.A.N. protects keys, the server and the admin page is described in [docs/security.md](docs/security.md).
